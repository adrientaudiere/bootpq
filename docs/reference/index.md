# Package index

## Bootstrapping by rarefaction permutations

Run statistical analyses across many rarefaction permutations of a
phyloseq object and summarise the results.

- [`adonis_rarperm_pq()`](https://adrientaudiere.github.io/bootpq/reference/adonis_rarperm_pq.md)
  : Permanova (adonis) on permutations of rarefaction even depth
- [`hill_test_rarperm_pq()`](https://adrientaudiere.github.io/bootpq/reference/hill_test_rarperm_pq.md)
  : Test multiple times effect of factor on Hill diversity with
  different rarefaction even depth
- [`var_par_rarperm_pq()`](https://adrientaudiere.github.io/bootpq/reference/var_par_rarperm_pq.md)
  : Partition the Variation of a phyloseq object with rarefaction
  permutations
